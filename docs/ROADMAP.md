# Roadmap

Each phase ends with passing tests, lint and type checks, and a build, and the app stays runnable. A phase is marked done only after verification.
Every phase respects the hosting constraints in `ARCHITECTURE.md` §1: portable DB, no Redis/Celery/Docker in production, and free/mock providers by default.

## Open decisions for the owner
1. **Hosting details**: see DEPLOYMENT.md §0. This blocks only Phase 27; building continues meanwhile.
2. Final brand name (currently "BoltRun", configurable).
3. Production AI provider: stays `none` (basic mode) until you choose one. Nothing is subscribed automatically.
   Semantic search runs with the built-in `hashing` embedder everywhere; the local sentence-transformers model needs a
   VPS (about 1 GB RAM, PyTorch), so whether to use it depends on the hosting answer.
4. Razorpay and WhatsApp Business accounts: needed only when going live with those channels.

## Decided (2026-10-05)
- Phase numbering 15 Commerce core / 16 Storefront / 17 Loyalty / 18–27 former 15–24: accepted.
- Credits: pay up to 20 % of an order; expire 90 days after they are earned; refunded returns restore the
  proportional credits used on those items under their original expiry; rules configurable; no fake balances.
- COD: maximum order value ₹10,000, configurable by an administrator; no product/category exclusions initially.
